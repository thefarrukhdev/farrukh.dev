## ✨ Key Features
- **Monochrome Design System:** A clean, distraction-free UI with dynamic Dark/Light theme switching.
- **Advanced Typography & Layouts:** Precision-engineered layouts with pixel-perfect responsive design.
- **Smooth Scrolling (Lenis):** Integrated hardware-accelerated smooth scrolling for a premium UX.
- **WebGL Flow Shaders:** Custom signature shaders for interactive visual elements.
- **Type-Safe Architecture:** Strict TypeScript configurations ensuring zero runtime type errors.
- **Performance First:** SEO-optimized, pre-rendered pages, and optimized asset delivery scoring ~100 on Lighthouse.

## 🚀 Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS + CSS Modules
- **Language:** TypeScript
- **Package Manager:** `pnpm` (Chosen for strict dependency resolution and extreme speed)
- **Animations/Scroll:** Lenis, Framer Motion

## 💻 Getting Started
To run this project locally, ensure you have [Node.js](https://nodejs.org/) and [pnpm](https://pnpm.io/) installed.

```bash
# 1. Clone the repository
git clone https://github.com/thefarrukhdev/farrukh.dev.git

# 2. Navigate to the project directory
cd farrukh.dev

# 3. Install dependencies using pnpm
pnpm install

# 4. Start the development server
pnpm dev
```
Visit `http://localhost:3000` to view the application.
